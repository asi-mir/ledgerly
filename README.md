# Ledgerly 🦥

A Telegram bot for people who are too lazy to track their spending. Send a photo of a
receipt; Gemma reads it and plain code checks that the items add up. Tell the bot about
family events in plain chat; TabPFN predicts the rest of the pay period and tells you
**Wall Day**, the day the budget runs out.

Work in progress. Full guide coming soon.
